# FoodLink Backend & AI Chatbot Services

This directory is designated for the FoodLink backend API services and the AI Chatbot engine.

## Services Architecture

- **Backend API**:
  - Surplus Food Donation Management (Donor Portal)
  - Shelter Meal Demand & Real-Time Matching Engine
  - Logistics, Volunteer Driver Missions & Route Dispatch
  - CSR Impact Analytics & Tax Exemption Reporting

- **AI Chatbot**:
  - Conversational Assistant for Food Donors and Volunteers
  - Real-time Rescue Mission Status Tracking
  - Intelligent FAQ and Nutrition Intake Support
