# FoodLink - Surplus Food Redistribution Platform

FoodLink connects surplus food from banquets, caterers, and restaurants with verified shelters and community kitchens in real time.

## Project Structure

`
├── frontend/    # Next.js 14 Web Application (Scroll Story Canvas, Dashboards, Role Portals)
└── backend/     # Backend API Services & AI Chatbot Engine
`

## Quick Start (Frontend)

To run the frontend locally:

`ash
cd frontend
npm install
npm run dev
`

Or from the repository root:
`ash
npm run dev
`

Open [http://localhost:3000](http://localhost:3000) to view the application.
